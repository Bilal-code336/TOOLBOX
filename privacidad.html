🔒 Política de Privacidad

Última actualización: septiembre de 2026

En TOOLBOX nos preocupamos por la privacidad de nuestros usuarios. Esta Política de Privacidad explica qué información puede ser procesada cuando utilizas nuestro sitio web y nuestras herramientas.

1. Información que proporcionas

Algunas herramientas de TOOLBOX pueden permitirte introducir textos, preguntas u otra información para utilizar determinadas funciones.

La información introducida en una herramienta puede ser procesada para proporcionar el resultado solicitado.

2. Herramientas de inteligencia artificial

Algunas funciones de TOOLBOX utilizan servicios de inteligencia artificial de terceros para generar respuestas o procesar el contenido enviado por el usuario.

Los datos necesarios para proporcionar estas funciones pueden ser enviados al servicio correspondiente para poder generar la respuesta.

3. Información técnica

Al visitar un sitio web pueden recopilarse determinados datos técnicos, como información relacionada con el navegador, el dispositivo, la dirección IP y datos necesarios para garantizar el funcionamiento y la seguridad del servicio.

4. Cookies

TOOLBOX puede utilizar cookies u otras tecnologías similares para determinadas funciones del sitio web.

Si en el futuro se utilizan servicios publicitarios, analíticos u otros servicios de terceros que empleen cookies, esta política podrá actualizarse para explicar su utilización.

5. Servicios de terceros

TOOLBOX puede utilizar servicios de terceros para proporcionar determinadas funciones, como servicios de inteligencia artificial, alojamiento, seguridad, análisis o publicidad.

Estos servicios pueden procesar determinados datos de acuerdo con sus propias políticas de privacidad.

6. Publicidad

Si TOOLBOX incorpora servicios publicitarios como Google AdSense, esta política podrá actualizarse para explicar el funcionamiento de dichos servicios, incluyendo las cookies y tecnologías utilizadas para mostrar publicidad.

7. Seguridad

Adoptamos medidas razonables para mantener la seguridad del sitio web y proteger la información frente a usos no autorizados.

8. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando TOOLBOX incorpore nuevas funciones, servicios o cambios en su funcionamiento.

Cuando se realicen cambios importantes, se actualizará la fecha indicada al principio de esta página.

9. Contacto

Si tienes preguntas relacionadas con esta Política de Privacidad o con el tratamiento de información en TOOLBOX, puedes utilizar la página de contacto del sitio web.
